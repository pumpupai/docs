The Pump Up REST API mirrors the SDK: every primitive — approvals, information requests, handoffs, routing — is available over HTTP for use from languages or environments where the SDK isn't a fit.

## Authentication

All requests require an `Authorization` header with your API key:

```http
Authorization: Bearer pk_live_...
```

Get an API key from the [dashboard](https://app.pumpup.dev).

## Base URL

```
https://api.pumpup.dev/v1
```

## Use the SDK first

For Python, TypeScript, and Java, the SDK handles retries, polling, webhook validation, and typed responses for you. Reach for the REST API only when those aren't an option.
