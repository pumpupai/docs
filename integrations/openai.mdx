The [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) wraps the model loop, tool execution, and handoffs into a single `Agent` + `Runner` API. The natural integration point for Pump Up is inside a function tool: when the model calls a sensitive tool, the tool body checks Pump Up before it acts.

## Install

<CodeGroup>


## Minimum working example

<CodeGroup>
```python Python
import os, asyncio
from agents import Agent, Runner, function_tool
from pumpup import PumpUp

pumpup = PumpUp(api_key=os.environ["PUMPUP_API_KEY"])

@function_tool
def process_claim(claim_id: str, amount_usd: float) -> str:
    """Pay out an insurance claim."""
    if amount_usd > 1000:
        result = pumpup.approvals.create(
            queue="approve_claim",
            params={"amount_usd": amount_usd, "claim_id": claim_id},
        )
        if result.status not in ("approved", "edited"):
            return f"Not paid — reviewer status: {result.status}"
        amount_usd = result.params["amount_usd"]
    pay_out(claim_id, amount_usd)
    return f"Paid out ${amount_usd:.2f} for {claim_id}"

agent = Agent(
    name="Claims Agent",
    instructions="Resolve insurance claims using process_claim.",
    tools=[process_claim],
)

asyncio.run(Runner.run(agent, "Process claim CLM-83472 for $8400."))
```

```typescript TypeScript
import { Agent, run, tool } from "@openai/agents";
import { z } from "zod";
import { PumpUp } from "@pumpup/sdk";

const pumpup = new PumpUp({ apiKey: process.env.PUMPUP_API_KEY! });

const processClaim = tool({
  name: "process_claim",
  description: "Pay out an insurance claim.",
  parameters: z.object({ claimId: z.string(), amountUsd: z.number() }),
  async execute({ claimId, amountUsd }) {
    if (amountUsd > 1000) {
      const result = await pumpup.approvals.create({
        queue: "approve_claim",
        params: { claimId, amountUsd },
      });
      if (result.status !== "approved" && result.status !== "edited") {
        return `Not paid — reviewer status: ${result.status}`;
      }
      amountUsd = result.params.amountUsd;
    }
    await payOut(claimId, amountUsd);
    return `Paid out $${amountUsd} for ${claimId}`;
  },
});

const agent = new Agent({
  name: "Claims Agent",
  instructions: "Resolve insurance claims using process_claim.",
  tools: [processClaim],
});

await run(agent, "Process claim CLM-83472 for $8400.");
```
</CodeGroup>

## Walkthrough

1. The model decides to call `process_claim`. The Agents SDK runs the tool body.
2. The body threshold-checks the amount and, for anything above $1,000, calls Pump Up.
3. The reviewer assigned to `approve_claim` approves, edits, or rejects.
4. On approve or edit, the body pays out using `result.params.amount_usd` (which reflects edits). On reject or timeout, the tool returns a string the model sees as the tool result and can react to conversationally.

## Other patterns

- **Guardrails for hard rules.** Use the SDK's `input_guardrail` / `output_guardrail` to block requests before the agent ever sees them. Save Pump Up for *judgment* gates where a human needs to weigh in.
- **Hooks for cross-cutting gating.** If many tools should be gated, use a lifecycle hook to check the tool name and call Pump Up centrally instead of repeating the check in each tool body.
- **Agent handoffs** (the SDK's term) are different from Pump Up's [Handoffs](/concepts/handoffs) — SDK handoffs hand control between agents; Pump Up handoffs hand control to a person. Use Pump Up's `handoffs.create` from inside a tool when no other agent can finish the job.

## Production notes

- **Routing is server-side.** Reviewers, thresholds, and SLAs for `approve_claim` are configured in the [dashboard](https://app.pumpup.dev), not in your tool.
- **Long approvals.** If reviewers can take hours, switch to the async/webhook pattern so the agent process doesn't block. See [Approvals](/concepts/approvals).
