The Anthropic SDK exposes tool calls as `tool_use` content blocks on the assistant message. The natural integration point for Pump Up is the moment between Claude returning a `tool_use` block and your code executing it: pause, ask a human, then run the tool only if they approve.

## Minimum working example

<CodeGroup>
```python Python
import os
from anthropic import Anthropic
from pumpup import PumpUp

anthropic = Anthropic()
pumpup = PumpUp(api_key=os.environ["PUMPUP_API_KEY"])

response = anthropic.messages.create(
    model="claude-opus-4-7",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Process the claim for CLM-83472, $8400."}],
    tools=[{
        "name": "process_claim",
        "input_schema": {"type": "object", "properties": {
            "claim_id": {"type": "string"},
            "amount_usd": {"type": "number"},
        }},
    }],
)

for block in response.content:
    if block.type == "tool_use" and block.name == "process_claim":
        result = pumpup.approvals.create(
            queue="approve_claim",
            params={
                "amount_usd": block.input["amount_usd"],
                "claim_id": block.input["claim_id"],
            },
        )
        if result.status in ("approved", "edited"):
            process_claim(**result.params)
```

```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";
import { PumpUp } from "@pumpup/sdk";

const anthropic = new Anthropic();
const pumpup = new PumpUp({ apiKey: process.env.PUMPUP_API_KEY! });

const response = await anthropic.messages.create({
  model: "claude-opus-4-7",
  max_tokens: 1024,
  messages: [{ role: "user", content: "Process the claim for CLM-83472, $8400." }],
  tools: [{
    name: "process_claim",
    input_schema: { type: "object", properties: {
      claim_id: { type: "string" },
      amount_usd: { type: "number" },
    }},
  }],
});

for (const block of response.content) {
  if (block.type === "tool_use" && block.name === "process_claim") {
    const input = block.input as { claim_id: string; amount_usd: number };
    const result = await pumpup.approvals.create({
      queue: "approve_claim",
      params: { amountUsd: input.amount_usd, claimId: input.claim_id },
    });
    if (result.status === "approved" || result.status === "edited") {
      await processClaim(result.params);
    }
  }
}
```
</CodeGroup>

## Walkthrough

1. Claude returns one or more content blocks. A `tool_use` block means it wants to call a tool.
2. Before executing the tool, your code calls `pumpup.approvals.create` with the proposed arguments.
3. The reviewer assigned to the `approve_claim` queue sees the action and approves, edits, or rejects it.
4. On approve or edit, your code runs the tool with `result.params`.

## Resume behavior

To continue the conversation, send Claude a `tool_result` block in the next user message. The block's `content` should explain what happened — the tool's output if it ran, or the rejection note if it didn't.

```python
followup = anthropic.messages.create(
    model="claude-opus-4-7",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "Process the claim for CLM-83472, $8400."},
        {"role": "assistant", "content": response.content},
        {"role": "user", "content": [{
            "type": "tool_result",
            "tool_use_id": block.id,
            "content": f"Status: {result.status}. Notes: {result.notes or ''}",
        }]},
    ],
    tools=[...],
)
```

If the reviewer rejected the action, Claude will see the rejection and can respond conversationally rather than retrying the same call.

## Production notes

- **Gate sensitive tools, not all tools.** Read-only lookups don't need approval; payouts, sends, and deletes do.
- **Use prompt caching on the tools array** to keep the cost of the loop down across multiple turns.
- **Long approvals** should use the async/webhook pattern so your process doesn't block. See [Approvals](/concepts/approvals).
