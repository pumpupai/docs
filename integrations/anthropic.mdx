The [Claude Agent SDK](https://docs.claude.com/en/api/agent-sdk) gives you a Claude-powered agent with built-in tool execution, hooks, and skills. The natural integration point for Pump Up is a `PreToolUse` hook: when the model wants to call a sensitive tool, the hook checks Pump Up and either allows the call, denies it, or rewrites its arguments.

For agents that load skills, you can also ship Pump Up usage as a skill — see [Skills](/surfaces/skills).

## Minimum working example

<CodeGroup>
```python Python
import os, asyncio
from claude_agent_sdk import (
    ClaudeSDKClient,
    ClaudeAgentOptions,
    HookMatcher,
    tool,
    create_sdk_mcp_server,
)
from pumpup import PumpUp

pumpup = PumpUp(api_key=os.environ["PUMPUP_API_KEY"])

@tool("process_claim", "Pay out an insurance claim", {"claim_id": str, "amount_usd": float})
async def process_claim(args):
    pay_out(args["claim_id"], args["amount_usd"])
    return {"content": [{"type": "text", "text": f"Paid out ${args['amount_usd']} for {args['claim_id']}"}]}

claims_server = create_sdk_mcp_server(name="claims", tools=[process_claim])

async def gate_with_pumpup(input_data, tool_use_id, context):
    if input_data["tool_name"] != "mcp__claims__process_claim":
        return {}
    args = input_data["tool_input"]
    if args["amount_usd"] <= 1000:
        return {}
    result = pumpup.approvals.create(
        queue="approve_claim",
        params={"amount_usd": args["amount_usd"], "claim_id": args["claim_id"]},
    )
    if result.status in ("approved", "edited"):
        return {"hookSpecificOutput": {
            "hookEventName": "PreToolUse",
            "modifiedToolInput": result.params,
        }}
    return {"hookSpecificOutput": {
        "hookEventName": "PreToolUse",
        "permissionDecision": "deny",
        "permissionDecisionReason": f"Reviewer {result.status}: {result.notes or ''}",
    }}

options = ClaudeAgentOptions(
    mcp_servers={"claims": claims_server},
    allowed_tools=["mcp__claims__process_claim"],
    hooks={"PreToolUse": [HookMatcher(matcher="mcp__claims__process_claim", hooks=[gate_with_pumpup])]},
)

async def main():
    async with ClaudeSDKClient(options=options) as client:
        await client.query("Process claim CLM-83472 for $8400.")
        async for message in client.receive_response():
            print(message)

asyncio.run(main())
```

```typescript TypeScript
import { query, tool, createSdkMcpServer } from "@anthropic-ai/claude-agent-sdk";
import { z } from "zod";
import { PumpUp } from "@pumpup/sdk";

const pumpup = new PumpUp({ apiKey: process.env.PUMPUP_API_KEY! });

const processClaim = tool(
  "process_claim",
  "Pay out an insurance claim",
  { claim_id: z.string(), amount_usd: z.number() },
  async (args) => {
    await payOut(args.claim_id, args.amount_usd);
    return { content: [{ type: "text", text: `Paid out $${args.amount_usd} for ${args.claim_id}` }] };
  },
);

const claimsServer = createSdkMcpServer({ name: "claims", tools: [processClaim] });

const gateWithPumpUp = async (input: any) => {
  if (input.tool_name !== "mcp__claims__process_claim") return {};
  const args = input.tool_input;
  if (args.amount_usd <= 1000) return {};
  const result = await pumpup.approvals.create({
    queue: "approve_claim",
    params: { amountUsd: args.amount_usd, claimId: args.claim_id },
  });
  if (result.status === "approved" || result.status === "edited") {
    return { hookSpecificOutput: { hookEventName: "PreToolUse", modifiedToolInput: result.params } };
  }
  return { hookSpecificOutput: {
    hookEventName: "PreToolUse",
    permissionDecision: "deny",
    permissionDecisionReason: `Reviewer ${result.status}: ${result.notes ?? ""}`,
  }};
};

for await (const msg of query({
  prompt: "Process claim CLM-83472 for $8400.",
  options: {
    mcpServers: { claims: claimsServer },
    allowedTools: ["mcp__claims__process_claim"],
    hooks: { PreToolUse: [{ matcher: "mcp__claims__process_claim", hooks: [gateWithPumpUp] }] },
  },
})) {
  console.log(msg);
}
```
</CodeGroup>

## Walkthrough

1. The agent decides to call `process_claim`. The Claude Agent SDK fires the `PreToolUse` hook before the call.
2. The hook checks the threshold, sends the proposed arguments to Pump Up, and waits.
3. The reviewer approves, edits, or rejects.
4. On approve or edit, the hook returns `modifiedToolInput` (so any reviewer edits take effect) and the tool runs. On reject or timeout, the hook denies the call with a reason — Claude sees the denial and responds to the user without retrying.

## Why a hook instead of a tool wrapper

The Claude Agent SDK runs tools inside its own process. Wrapping a tool body would also work, but the hook surface gives you:

- A single place to gate every sensitive tool, with `matcher` selecting which calls run the hook
- A first-class way to deny a call (rather than returning a string the model has to interpret)
- The ability to rewrite arguments (`modifiedToolInput`) when the reviewer edits

## Skills

If you'd rather have the *model* decide when to involve Pump Up — instead of code-gating specific tools — ship the behavior as a [skill](/surfaces/skills). Skills are loaded by the Claude Agent SDK on initialization and the model picks them up when their description matches.

## Production notes

- **Routing is server-side.** Reviewers, thresholds, and SLAs for `approve_claim` are configured in the [dashboard](https://app.pumpup.dev).
- **Long approvals.** Switch to the async/webhook pattern so the hook doesn't block. See [Approvals](/concepts/approvals).
