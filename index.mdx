---

Pump Up is an operational control plane for your autonomous agents. It provides the infrastructure for them to ask for approvals, decisions, or information from you or your team.

## How it works

Pump Up integrates with any existing agent framework, such as OpenAI Agents SDK, LangChain, or Claude Agent SDK. You can import it as a library or use it as a Skill.

Agents use Pump Up's API to create and route tickets which require human response.

## Types of tickets

Pump Up supports three ticket types.

<Columns cols={2}>
  <Card title="Approvals" icon="circle-check" href="/concepts/approvals">

  <Card title="Information requests" icon="circle-question" href="/concepts/info-requests">

  <Card title="Handoffs" icon="arrow-right-arrow-left" href="/concepts/handoffs">
