---
title: "Pump Up"
description: "Pump Up manages how your AI agents get help from humans."
---

Pump Up gives your AI agents the ability request information from the humans in your company. It is really easy to integrate with any existing agent framework, and we provide a full service platform for managing, routing, interfacing with, and logging these tickets.

## Primitives

Pump Up supports four ticket types.

<Columns cols={2}>
  <Card title="Approvals" icon="circle-check" href="/concepts/approvals">
    The agent proposes a sensitive action. A human approves, rejects, or edits.
  </Card>

  <Card title="Information requests" icon="circle-question" href="/concepts/info-requests">
    The agent is missing context it can't find. A human supplies it.
  </Card>

  <Card title="Handoffs" icon="arrow-right-arrow-left" href="/concepts/handoffs">
    The agent has done all it can. A human takes over and finishes the job.
  </Card>

  <Card title="Routing" icon="signs-post" href="/concepts/routing">
    A human picks the next step in the workflow. Typically used in graph-based agents.
  </Card>
</Columns>
