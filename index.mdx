**Pump Up lets your AI agents get help from humans.**

You should use Pump Up when your agents need approvals, missing informations, or to handoff to your team.

Add Pump Up to an existing agent in a few lines of code and it routes tickets to the right reviewer and returns the answer to your agents. You can enforce SLAs and have a full audit trail of who decided what and why.

## Primitives

Every Pump Up interaction is one of four common request types.

<Columns cols={2}>
  <Card title="Approvals" icon="circle-check" href="/concepts/approvals">
    The agent proposes a sensitive action. A human approves, rejects, or edits.
  </Card>

  <Card title="Information requests" icon="circle-question" href="/concepts/info-requests">
    The agent is missing context it can't find. A human supplies it.
  </Card>

  <Card title="Handoffs" icon="arrow-right-arrow-left" href="/concepts/handoffs">
    The agent has done all it can. A human takes over and finishes the job.
  </Card>

  <Card title="Routing" icon="signs-post" href="/concepts/routing">
    A human decides the next step in the workflow.
  </Card>
</Columns>
